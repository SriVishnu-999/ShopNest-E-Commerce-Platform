SHOPNEST QUICK START
====================

1) Install .NET 9 SDK, SQL Server LocalDB, Node.js 22+

2) Backend terminal:
   cd server\ShopNest.Api
   dotnet restore
   dotnet run --launch-profile http

3) Frontend terminal:
   cd client
   copy .env.example .env
   npm install
   npm run dev

4) Open http://localhost:5173
